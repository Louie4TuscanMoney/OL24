🌟 HELIOS OFFICIAL - PACKAGE SUMMARY
=====================================

PACKAGE NAME: heliosofficial
CREATED: October 24, 2025
PURPOSE: Intelligent Feature Engineering System for Mamba Mentality Model

WHAT IS HELIOS?
---------------
Helios is the feature extraction powerhouse that transforms raw NBA game data
into 67 high-dimensional features used by the Mamba Mentality ML model.

KEY FEATURES:
- 67-feature extraction pipeline (18 pattern + 4 statistical + 5 spectral + 10 momentum + 10 autocorr + 20 NBA stats)
- Auto feature mining (720+ candidates → elite 67)
- Real-time extraction (<100ms)
- Play-by-play analysis (possession, shot quality, momentum)
- Spectral signal processing (FFT, wavelet, chaos theory)

PACKAGE STRUCTURE:
------------------
core/               → Feature extraction engines (extraction, mining, training)
src/                → Modular source code (collectors, feature_engineering, transformers)
documentation/      → Complete system docs, results, analysis
examples/           → Usage examples and demos
README.md           → Comprehensive documentation

CORE COMPONENTS:
----------------
1. helios_proper_extraction.py     → 67-feature extraction
2. phase_3_extract_720_features.py → Full feature mining (720+)
3. phase_4_lasso_mine_elite.py     → LASSO feature selection
4. phase_5_train_final_model.py    → Final model training
5. pbp_collector.py                → Play-by-play data collection
6. feature_builder.py              → Feature construction logic
7. momentum_analyzer.py            → Momentum feature extraction
8. signal_transforms.py            → Spectral/FFT transforms

PERFORMANCE:
------------
- Feature extraction: <100ms
- Mamba MAE: 6.8 points (training), 9.3 points (test)
- Features: 67 elite features from 720+ candidates
- Training data: 5,529 games
- Test data: 1,383 games

INTEGRATION:
------------
- Mamba Mentality Model → Provides 67 features for predictions
- OntoRisk System       → Features used for probability calibration
- Live Trading Engine   → Real-time feature extraction

USAGE:
------
# Extract 67 features
from heliosofficial.core.helios_proper_extraction import extract_67_features
features = extract_67_features(game_data)

# Run auto feature mining
from heliosofficial.examples.auto_helios_feature_mining import run_auto_mining
elite_features = run_auto_mining(training_data, n_features=67)
