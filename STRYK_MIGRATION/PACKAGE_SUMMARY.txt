TROUBLESHOOTING:
----------------
Export fails:
  → Check backend URL in 01_export_old_data.py
  → Use ngrok if backend is local

Postgres migration fails:
  → Check POSTGRES_URL is correct
  → Test connection: railway run psql $POSTGRES_URL
  → Re-run schema: \i schemas/postgres_schema.sql

Redis connection fails:
  → Check REDIS_URL is correct
  → Test connection: redis-cli -u $REDIS_URL
  → Restart Redis: railway restart redis

Railway deployment fails:
  → Check requirements.txt has all dependencies
  → Add Procfile: web: uvicorn main:app --host 0.0.0.0 --port $PORT
  → Set environment variables in Railway dashboard
