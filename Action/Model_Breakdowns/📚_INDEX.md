Every markdown report contains:

### **1. Model Specifications**
- Architecture details
- Feature count
- Training/testing split
- Full performance metrics

### **2. Error Distribution**
- 7 error bins (0-2, 2-5, 5-8, 8-12, 12-15, 15-20, 20+ pts)
- Percentages and counts
- Cumulative accuracy at key thresholds

### **3. Performance by Game Type**
- 5 game states: Very Close, Close, Moderate, Large Lead, Blowout
- 4 outcome types: Was Close, Lead Held, Comeback/Flip, Tightened
- MAE, median, and counts for each category

### **4. Directional Accuracy**
- Overall winner prediction rate
- MAE when direction is correct vs wrong
- Percentage breakdowns

### **5. Error Quartiles**
- 0th, 25th, 50th, 75th, 90th, 95th, 100th percentiles
- Shows how errors are distributed

### **6. Confidence Zones**
- **HIGH** (Error ≤ 5 pts): Percentage, avg error, direction accuracy
- **MEDIUM** (5-12 pts): Percentage, avg error, direction accuracy
- **RISK** (> 15 pts): Percentage, avg error, most common outcomes

### **7. Bias Analysis**
- Overall mean and median signed error
- Whether model over/under-predicts
- Bias by game state

### **8. Where Model Excels**
- Top 3 game types with lowest MAE

### **9. Where Model Struggles**
- Top 3 game types with highest MAE

### **10. Key Insights**
- 5 critical takeaways per model
